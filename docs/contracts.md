## 1. Services and ports

| Service | Container | Port | Published to host | Notes |
|---|---|---|---|---|
| api | `api` | 8000 | yes (`8000:8000`) | FastAPI orchestrator + static chat UI |
| mock-uber | `mock-uber` | 8001 | no | Guest Rides mock + driver simulator |
| floci | `floci` | 4566 | no | Validated DynamoDB emulator, pinned to `floci/floci:1.5.33` |
| iac | `iac` | - | no | Runs Terraform apply against Floci, exits 0 |

Startup order: `floci` (healthcheck `curl -sf http://localhost:4566/_localstack/health`)
-> `iac` (`depends_on: floci: condition: service_healthy`; runs apply, exits)
-> `api` (`depends_on: iac: condition: service_completed_successfully`, plus `mock-uber: condition: service_started`).

Local development mounts `floci-data:/app/data` and persists Terraform state in a separate named
volume. CI uses `FLOCI_STORAGE_MODE=memory` and removes its volumes after the job.

## 3. DynamoDB tables (created by Terraform, module `infra/modules/data`)

All tables `PAY_PER_REQUEST`, region `ap-southeast-1`.

| Table | PK | SK | GSI | TTL attribute |
|---|---|---|---|---|
| `sessions` | `session_id` (S) | - | - | `expires_at` |
| `trips` | `trip_id` (S) | - | `by_session`: PK `session_id` (S) | - |
| `action_log` | `session_id` (S) | `entry_key` (S) | - | - |
| `pending_actions` | `token` (S) | - | - | `expires_at` |

**DynamoDB TTL is lazy (deletion can lag hours).** Expiry MUST also be checked in code wherever it
matters (pending-action claim, session load).

ID conventions:
- `session_id`: UUID v4 string, generated by the browser, persisted in localStorage
- `trip_id`: `f"uber:{provider_request_id}"` (prefix = provider name; makes webhook lookup a key get)
- `correlation_id`: `f"act_{uuid4().hex[:12]}"` - one per attempt, spans all its log phases
- `entry_key`: `f"{datetime.now(timezone.utc).isoformat()}#{uuid4().hex[:6]}"`
- `place_id`: `f"plc_{uuid4().hex[:8]}"`
- pending action `token`: `secrets.token_urlsafe(32)`

## 4. Shared Pydantic models (`api/app/models.py`, verbatim)

```python
from datetime import datetime
from enum import Enum
from typing import Literal
from pydantic import BaseModel

class LatLng(BaseModel):
    lat: float
    lng: float

class Place(BaseModel):
    place_id: str
    name: str            # OneMap SEARCHVAL
    address: str         # OneMap ADDRESS
    postal: str | None   # OneMap POSTAL ("NIL" -> None)
    location: LatLng

class Quote(BaseModel):
    fare_id: str
    product_id: str
    product_name: str            # e.g. "UberX"
    capacity: int
    price_value: float
    price_display: str           # e.g. "SGD 15.50"
    currency: str                # "SGD"
    pickup_eta_minutes: int
    duration_minutes: int
    distance_km: float
    surge_multiplier: float
    expires_at: datetime         # UTC
    pickup: LatLng
    dropoff: LatLng
    pickup_label: str            # human-readable, e.g. Place.name
    dropoff_label: str

class GuestProfile(BaseModel):
    first_name: str
    last_name: str
    phone_number: str            # E.164

class TripStatus(str, Enum):
    processing = "processing"
    no_drivers_available = "no_drivers_available"
    accepted = "accepted"
    arriving = "arriving"
    in_progress = "in_progress"
    completed = "completed"
    driver_canceled = "driver_canceled"
    rider_canceled = "rider_canceled"
    driver_redispatched = "driver_redispatched"

# Legal forward transitions (mock enforces when simulating; api enforces when applying webhooks)
LEGAL_TRANSITIONS: dict[TripStatus, set[TripStatus]] = {
    TripStatus.processing: {TripStatus.accepted, TripStatus.no_drivers_available},
    TripStatus.accepted: {TripStatus.arriving, TripStatus.driver_canceled,
                          TripStatus.rider_canceled, TripStatus.driver_redispatched},
    TripStatus.driver_redispatched: {TripStatus.accepted},
    TripStatus.arriving: {TripStatus.in_progress, TripStatus.driver_canceled,
                          TripStatus.rider_canceled},
    TripStatus.in_progress: {TripStatus.completed},
    TripStatus.no_drivers_available: set(),
    TripStatus.completed: set(),
    TripStatus.driver_canceled: set(),
    TripStatus.rider_canceled: set(),
}

CANCELLABLE_STATUSES = {TripStatus.processing, TripStatus.accepted, TripStatus.arriving}

class Driver(BaseModel):
    name: str
    rating: float

class ProviderTripState(BaseModel):
    provider_request_id: str
    status: TripStatus
    driver: Driver | None = None

class Trip(BaseModel):
    trip_id: str                 # "uber:<provider_request_id>"
    provider: str                # "uber"
    provider_request_id: str
    session_id: str
    status: TripStatus
    quote: Quote
    driver: Driver | None = None
    last_event_id: str | None = None
    created_at: datetime
    updated_at: datetime

class PendingAction(BaseModel):
    token: str
    session_id: str
    action_type: Literal["book", "cancel"]
    payload: dict                # book: {"quote": Quote.model_dump(mode="json")}; cancel: {"trip_id": str}
    correlation_id: str
    created_at: datetime
    expires_at: int              # epoch seconds; ALSO checked in code on claim

class ActionLogEntry(BaseModel):
    session_id: str
    entry_key: str
    correlation_id: str
    phase: Literal["requested", "verified", "executed", "outcome"]
    actor: Literal["llm", "user", "webhook", "system"]
    tool: str | None = None
    payload: dict
    ts: datetime

class Session(BaseModel):
    session_id: str
    messages: list[dict] = []            # OpenAI chat-format dicts, capped at 40 (drop oldest)
    places: dict[str, Place] = {}        # place_id -> Place, cap 20 (drop oldest inserted)
    quotes: dict[str, Quote] = {}        # fare_id -> Quote; REPLACED wholesale on each get_quotes
    created_at: datetime
    updated_at: datetime
    expires_at: int                      # epoch seconds, now + 24h, refreshed on write
```

```python

from typing import Protocol
from app.models import LatLng, Quote, GuestProfile, ProviderTripState

class RideProvider(Protocol):
    async def get_quotes(self, pickup: LatLng, dropoff: LatLng,
                         pickup_label: str, dropoff_label: str) -> list[Quote]: ...
    async def book(self, quote: Quote, guest: GuestProfile) -> ProviderTripState: ...
    async def get_trip(self, provider_request_id: str) -> ProviderTripState: ...
    async def cancel(self, provider_request_id: str) -> ProviderTripState: ...

# api/app/geocode/base.py
class Geocoder(Protocol):
    async def search(self, query: str) -> list[Place]: ...   # Place.place_id left "" ; caller assigns

# api/app/ws/publisher.py
class WsPublisher(Protocol):
    async def publish(self, session_id: str, message: dict) -> None: ...   # no-op if not connected

# api/app/agent/service.py (implemented in RB-105, called by RB-106)
class AgentService(Protocol):
    async def handle_user_message(self, session_id: str, text: str) -> None:
        """Runs the agent loop; pushes all output via WsPublisher. Never raises to caller."""

# api/app/registry.py (RB-101; the wiring seam that lets RB-105 and RB-106 build in parallel)
def set_publisher(p: WsPublisher) -> None: ...
def get_publisher() -> WsPublisher: ...        # default: NoopPublisher (publish does nothing)
def set_agent_service(s: AgentService) -> None: ...
def get_agent_service() -> AgentService: ...   # default: raises RuntimeError("agent service not wired")
# RB-105's deps.py calls set_agent_service(...) at import time; RB-101's main.py startup does
# `try: import app.deps` / `except ImportError: log warning` so the api boots at every wave.
# RB-106's ws module calls set_publisher(manager) at startup and get_agent_service() per message.
```

Storage repositories (`api/app/storage/`, implemented RB-103):

```python
class SessionRepo:
    async def get(self, session_id: str) -> Session | None      # None if absent OR code-expired
    async def put(self, session: Session) -> None                # refreshes expires_at

class TripRepo:
    async def put(self, trip: Trip) -> None
    async def get(self, trip_id: str) -> Trip | None
    async def list_by_session(self, session_id: str) -> list[Trip]   # via GSI by_session
    async def apply_status_event(self, trip_id: str, event_id: str,
                                 new_status: TripStatus,
                                 driver: Driver | None) -> Trip | None
        # Conditional update: returns updated Trip, or None if (a) trip unknown,
        # (b) event_id == stored last_event_id (duplicate), or
        # (c) transition illegal per LEGAL_TRANSITIONS. Sets last_event_id, updated_at.

class ActionLogRepo:
    async def append(self, entry: ActionLogEntry) -> None        # the ONLY public method

class PendingActionRepo:
    async def put(self, action: PendingAction) -> None
    async def claim(self, token: str) -> PendingAction | None
        # Atomic claim: conditional DELETE returning the old item (ReturnValues=ALL_OLD).
        # Returns None if absent/already claimed. Caller MUST also check expires_at
        # against now (DynamoDB TTL is lazy) and treat expired as a failed claim.
```

## 6. LLM tools (OpenAI function schemas, exact)

Read tools execute immediately. Write tools (`book_ride`, `cancel_ride`) NEVER execute from an LLM
call; they create a pending action + confirmation card (see design.md 6.2).

```json
[
 {"type":"function","function":{"name":"search_places",
   "description":"Search Singapore places (landmarks, buildings, postal codes) and return candidates with place_ids.",
   "parameters":{"type":"object","properties":{"query":{"type":"string"}},"required":["query"]}}},
 {"type":"function","function":{"name":"get_quotes",
   "description":"Get ride quotes between two previously searched places. Use place_ids returned by search_places.",
   "parameters":{"type":"object","properties":{
     "pickup_place_id":{"type":"string"},"dropoff_place_id":{"type":"string"}},
     "required":["pickup_place_id","dropoff_place_id"]}}},
 {"type":"function","function":{"name":"book_ride",
   "description":"Propose booking a quoted ride. Requires the user to confirm in the UI before anything is booked.",
   "parameters":{"type":"object","properties":{"fare_id":{"type":"string"}},"required":["fare_id"]}}},
 {"type":"function","function":{"name":"get_trip_status",
   "description":"Get current status of a trip in this session.",
   "parameters":{"type":"object","properties":{"trip_id":{"type":"string"}},"required":["trip_id"]}}},
 {"type":"function","function":{"name":"list_session_trips",
   "description":"List this session's trips with ids and statuses.",
   "parameters":{"type":"object","properties":{}}}},
 {"type":"function","function":{"name":"cancel_ride",
   "description":"Propose cancelling a trip. Requires the user to confirm in the UI before anything is cancelled.",
   "parameters":{"type":"object","properties":{"trip_id":{"type":"string"}},"required":["trip_id"]}}}
]
```

Grounding rules enforced in code (not prompts):
- `get_quotes` place_ids MUST exist in `session.places`, else refusal (the model cannot inject coordinates)
- `book_ride.fare_id` MUST exist in `session.quotes` and be unexpired, else refusal
- `get_trip_status` / `cancel_ride` trip_id MUST belong to the session (via `list_by_session`), else refusal
- A refusal = tool result `{"error": "<reason>"}` fed back to the model + `verified: rejected` log entry

## 7. api HTTP/WS surface

| Route | Method | Auth | Contract |
|---|---|---|---|
| `/` | GET | - | Serves `static/index.html` |
| `/healthz` | GET | - | `200 {"status":"ok"}` |
| `/ws` | WebSocket | `session_id` query param (UUID v4, validated) | JSON messages, section 8 |
| `/confirm` | POST | - | Body `{"token": str, "decision": "confirm"|"dismiss"}` -> `200 {"result": "executed"|"dismissed"|"expired"|"failed", "trip_id": str|null}` |
| `/webhooks/uber` | POST | Header `X-Webhook-Secret` (verified with `hmac.compare_digest`) | Body = webhook payload (section 9). Always `204` on authenticated requests (even unknown trip - logged, not actioned); `401` on bad/missing secret |

Rate limits (in-memory token bucket; single-instance MVP): user messages 20/min per session_id;
`/confirm` 10/min bucketed by token string (pre-claim the session is unknown). Exceeding -> WS
`error` message / HTTP 429.

## 9. mock-uber contract (Guest Rides mirror)

Auth middleware on all `/v1/*` routes: require `authorization: Bearer <anything>` AND
`x-uber-organizationuuid: <anything>` headers, else `401 {"code":"unauthorized"}`.

### POST /v1/guests/trips/estimates
Request: `{"pickup": {"latitude": float, "longitude": float}, "dropoff": {"latitude": float, "longitude": float}}`
Response `200`:

```json
{"product_estimates": [
  {"product": {"product_id": "uberx-sg", "display_name": "UberX", "capacity": 4,
     "product_group": "ridesharing",
     "cancellation": {"min_cancellation_fee": 6.0, "cancellation_grace_period_threshold_sec": 120}},
   "estimate_info": {"fare_id": "fare_<uuid4hex>", "pickup_estimate": 4,
     "estimate": {"low_estimate": 14, "high_estimate": 18, "display": "SGD 14-18", "currency_code": "SGD"},
     "fare": {"value": 15.5, "currency_code": "SGD", "display": "SGD 15.50",
              "expires_at": 1753430000, "fare_breakdown": [{"type": "base_fare", "value": 15.5, "name": "Base fare"}]},
     "trip": {"distance_estimate": 8.2, "distance_unit": "km", "duration_estimate": 1080}},
   "fulfillment_indicator": "GREEN"}]}
```

Products (fixed): `uberx-sg`/UberX/cap 4/multiplier 1.0 · `comfort-sg`/Comfort/cap 4/1.3 ·
`uberxl-sg`/UberXL/cap 6/1.6. Fare formula: `(4.0 + 0.9*km + 0.15*minutes) * product_multiplier * surge`,
haversine km, 30 km/h assumed speed, round to 2dp. `fare.expires_at` = now + 300s (epoch).
`MOCK_DETERMINISTIC=1`: no jitter, `pickup_estimate=4` always.

### POST /v1/guests/trips
Request: `{"guest": {"first_name": str, "last_name": str, "phone_number": "E.164"},
"product_id": str, "fare_id": str, "pickup": {"latitude","longitude"}, "dropoff": {"latitude","longitude"}}`
Validation: known `product_id` (`404 {"code":"invalid_product"}`), `fare_id` issued and unexpired
(`410 {"code":"fare_expired"}`), guest fields present with E.164 phone (`400 {"code":"invalid_guest"}`).
Response `200`: `{"request_id": "req_<uuid4hex>", "product_id": "...", "status": "processing",
"surge_multiplier": 1.0, "guest": {"guest_id": "guest_<uuid4hex>", ...echoed fields...}}`
Side effect: lifecycle simulation starts (section 10).

### GET /v1/guests/trips/{request_id}
`200 {"request_id": "...", "status": "<TripStatus>", "driver": null|{"name": "...", "rating": 4.8},
"pickup": {...}, "destination": {...}, "client_fare": "SGD 15.50"}` · unknown id `404 {"code":"not_found"}`

### DELETE /v1/guests/trips/{request_id}
If status in CANCELLABLE_STATUSES -> sets `rider_canceled`, emits webhook, `200` with GET-shape body.
Else `409 {"code":"not_cancellable", "status": "<current>"}`.

### POST /_sim/scenario  (test/demo control; NOT part of the Uber contract; no auth)
Body: `{"scenario": "no_drivers"|"driver_cancel"|"surge"|"reset", "surge_multiplier": 2.0}`
`no_drivers`: next created trip -> `no_drivers_available`. `driver_cancel`: next trip cancels after
`accepted`. `surge`: subsequent estimates apply the multiplier. `reset`: clear all. Response `200 {"applied": "<scenario>"}`.

## 10. Lifecycle simulation and webhooks

Happy path delays (seconds, each divided by `SIM_SPEED`; `MOCK_DETERMINISTIC=1` = all zero):
`processing -3s-> accepted -8s-> arriving -10s-> in_progress -20s-> completed`.
Driver assigned at `accepted` (fixed name list, rating in [4.6, 5.0]).
Every transition POSTs to `WEBHOOK_TARGET_URL` with header `X-Webhook-Secret: $WEBHOOK_SHARED_SECRET`:

```json
{"event_id": "evt_<uuid4hex>", "event_time": 1753430000,
 "event_type": "guests.trips.status_changed",
 "resource_href": "http://mock-uber:8001/v1/guests/trips/<request_id>",
 "meta": {"user_id": "mock-user", "org_uuid": "<UBER_ORG_UUID>",
          "resource_id": "<request_id>", "status": "<new_status>"}}
```

Delivery: retry up to 3 times, backoff 1s/2s/4s, on non-2xx or connection error; then drop (api
reconciles via GET). api dedupes on `event_id` (TripRepo.apply_status_event).

## 11. OneMap contract (external; from design.md 3.4, live-verified 2026-07-25)

- `GET {ONEMAP_BASE_URL}/api/common/elastic/search?searchVal=<q>&returnGeom=Y&getAddrDetails=Y&pageNum=1`
  with header `Authorization: <access_token>`. Response: `{"found": int, "totalNumPages": int,
  "pageNum": int, "results": [{"SEARCHVAL","BLK_NO","ROAD_NAME","BUILDING","ADDRESS","POSTAL",
  "X","Y","LATITUDE","LONGITUDE"}]}` - ALL values are strings; parse LATITUDE/LONGITUDE to float,
  parse failure = skip that result and log, never guess. `POSTAL` value `"NIL"` -> `None`.
- Token: `POST {ONEMAP_BASE_URL}/api/auth/post/getToken` body `{"email","password"}` ->
  `{"access_token": "...", "expiry_timestamp": "<epoch string>"}`; valid ~3 days. Fetch lazily on
  first search, cache in memory with expiry, refresh when within 1h of expiry or on any 401 (one
  retry). Token is a secret: never logged.

## 12. Action-log phase discipline

| Flow | Entries (phase / actor) |
|---|---|
| Read tool call | `requested`/llm -> `outcome`/llm (result summary or error) |
| Write tool call (gate) | `requested`/llm -> `verified`/system (ok: token created, or rejected: reason) |
| Confirm (user) | `verified`/user (claim ok, expired, or already-used) -> `executed`/system (provider call sent) -> `outcome`/system (provider response or error) |
| Dismiss (user) | `outcome`/user `{"result": "aborted_by_user"}` |
| Webhook | `outcome`/webhook `{"event_id", "status", "applied": bool}` (duplicates logged with `applied: false`) |

`payload` always includes enough to audit (tool args as proposed, provider endpoint + params on
`executed`, response/error body on `outcome`). Secrets never appear in payloads; guest PII MAY
appear in `executed` payloads (the action log is the access-controlled audit trail).
