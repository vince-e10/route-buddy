# Route Buddy

An AI agent for discovering, comparing, booking, tracking, and cancelling ride-hailing trips.
The MVP targets Singapore and uses a mocked Uber Guest Rides provider.

Implementation has not started. The approved design and frozen contracts are complete:

- [Requirements](docs/high-level-requirements.md)
- [Detailed design](docs/design.md)
- [Execution plan](docs/execution-plan.md)
- [GitHub Issues](https://github.com/vince-e10/route-buddy/issues)

All changes use feature branches and reviewed pull requests against `main`. Start with an open
issue and include `Closes #<issue>` in the pull request.
